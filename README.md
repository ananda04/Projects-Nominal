# Projects-Nominal

A collection of applications, hardware designs, and automation tools built for the Nominal Connect ecosystem.

## Projects Overview

### `ciRACK`
Configurations, soft-control utilities, and automation scripts for managing hardware test rack infrastructure and VISA-connected instrumentation.

### `connectBAMBU`
Nominal Connect application for integrating Bambu Lab 3D printers, processing G-code print instructions, and streaming telemetry to Nominal.

### `connectModule`
Custom hardware design and embedded setup for a standalone RS-232 to Ethernet adapter board running Connect Engine to enable no-code test rack instrument interfacing.

### `gem5-connect`
Nominal Connect runner and data processing pipeline for executing gem5 Garnet Network-on-Chip (NoC) synthetic traffic sweeps via Docker and streaming post-evaluation telemetry to Nominal Core.
